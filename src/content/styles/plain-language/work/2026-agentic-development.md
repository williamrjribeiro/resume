<b>Learning by building:</b> AI tools change every month, so I test them on real software. I do not just read about them. I use Claude Code and Cursor, including Cursor's cloud agents. I compare planning modes, prompting styles, and spec-driven frameworks such as GSD. I keep what works, drop what does not, and write down why.

<b>Evaluating AI agents:</b> I built Verdant, a private Tessl workspace with two skill packages. They teach AI agents when to use Git worktrees (separate working copies of one project) and when to use stacked pull requests (small, linked code changes). Verdant has nine levelled eval scenarios with weighted rubrics, blocking failures, and adversarial cases. They run against a pinned, Bash-validated fixture repository, which is a fixed practice project. I planned the work with GSD in 5 phases, 21 plans, and 56 tasks. Contract tests, path-scoped CI (automatic checks), and a verified publish dry-run back it up.

<b>Parallel agents, human review:</b> I directed background agents that worked in parallel Git worktrees. They built a 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook). I sent the hardest stories to a stronger model and the rest to a faster one. Then I reviewed the work and merged it as one pull request. The project reached 290 tracked issues and 199 commits in under four weeks.

<b>Specs and quality gates:</b> Every feature starts with a written spec and user stories. I track them in Beads, an issue tracker built for agents. The agents work behind a pre-commit hook that mirrors CI. They also use behavior-driven tests, Storybook, and screenshot-based visual checks. Hexkit, my contract-driven API generator, was also spec-first. I wrote an RFC (a design proposal) and a PRD (a product requirements document) before any code, then added a 90% coverage gate.

<b>Improving the process:</b> I change my workflow when the results tell me to. Review work and token costs piled up. So I moved from stacked pull requests to one epic branch. I replaced manual visual checks with screenshot comparison. I turned a long `AGENTS.md` into reusable skills. I packaged the lessons as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter).
