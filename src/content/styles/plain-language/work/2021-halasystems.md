<b>Engineering leadership:</b> I was promoted to Principal Engineer. I became the unofficial tech lead of one of the product teams. I led cross-functional teams and set the technical vision for secure web applications. I also worked in the front-end and back-end code every day. I took on many other tasks: defining the engineering culture, making technical stack decisions, keeping standards high across teams, shaping the technical side of hiring, mentoring, and more.

<b>AI-powered solutions:</b> I worked closely with AI researchers, ML specialists, and ETL data engineers. Together we delivered user-facing applications that use complex AI. I added audio processing for transcription, denoising, and translation in many languages. I then added image processing for humanitarian crisis response.

<b>Frontend architecture:</b> I designed mission-critical applications with React, TypeScript, and Next.js, using MUI components. I focused on Core Web Vitals, Google's measures of page speed and stability. I used React GL to build complex geospatial interfaces. They gave humanitarian early warning systems interactive maps.

<b>Performance optimization:</b> I used standard front-end profiling tools to find slow spots. This matters in the resource-constrained environments our users face. I used code-splitting, lazy loading, and SSR/SSG techniques to shrink bundle sizes and load times. I also improved how React renders pages, for a great UX.

<b>Progressive web applications:</b> I built offline-first PWAs, which are web apps that work like phone apps. They use local-first, optimistic UI and RTL (right-to-left language) support. Our users in Syria need them. Their environments are challenging, their connection comes and goes, and their mobile devices are low-cost.

<b>Modern development stack:</b> I moved many repositories to modern JavaScript development tools like pnpm, Vite, and Vitest. I replaced a couple of GraphQL-based applications with Next.js. Next.js renders pages on the server and makes API integration between client and server easy.

<b>Serverless architecture:</b> I designed and built distributed serverless applications with AWS CDK, SST, Serverless framework, and Terraform. This approach lowered our operational burden. It made security requirements easier to meet. It also gave us more speed and agility.
