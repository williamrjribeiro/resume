<b>Learning by building:</b> Ribeiro tests AI tools and techniques on real software, rather than only reading about them, because they change from one month to the next. He uses Claude Code and Cursor, including Cursor's cloud agents, and compares planning modes, prompting styles and spec-driven frameworks such as GSD. He keeps what works, drops what doesn't and writes down why.

<b>Evaluating AI agents:</b> Ribeiro built Verdant, a private Tessl workspace with two skill packages that teach agents when to use Git worktrees and when to use stacked pull requests. The workspace has nine leveled eval scenarios with weighted rubrics, blocking failures and adversarial cases, run against a pinned, Bash-validated fixture repository. He planned it with GSD in 5 phases, 21 plans and 56 tasks, and backed it with contract tests, path-scoped CI and a verified publish dry-run.

<b>Parallel agents, human review:</b> Ribeiro directed background agents in parallel Git worktrees to build a 19-story redesign of a guitar-lesson player using SolidJS, Bun and Storybook. He sent the hardest stories to a stronger model and the rest to a faster one, then reviewed and merged the work as one pull request. The project reached 290 tracked issues and 199 commits in under four weeks.

<b>Specs and quality gates:</b> Every feature starts with a written spec and user stories tracked in Beads, an issue tracker built for agents, Ribeiro said. The agents work behind a pre-commit hook that mirrors CI, with behavior-driven tests, Storybook and screenshot-based visual checks. Hexkit, his contract-driven API generator, also was spec-first: an RFC and a PRD before code, then a 90% coverage gate.

<b>Process changes:</b> Ribeiro changes his workflow when the results warrant it. He moved from stacked pull requests to one epic branch after review overhead and token costs piled up. He replaced manual visual checks with screenshot comparison and turned a long `AGENTS.md` into reusable skills. He packaged the lessons as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter).
