<b>Engineering leadership:</b> I became a Principal Engineer and the unofficial tech lead of one of the product teams. I led cross-functional teams and set the technical vision for secure web applications. I also contributed to the front-end and back-end codebases every day. I was responsible for many other things: defining the engineering culture, making technical stack decisions, keeping standards high across teams, shaping the technical parts of hiring, mentoring and more.

<b>AI-powered solutions:</b> I worked closely with AI researchers, ML specialists and ETL data engineers. Together we delivered user-facing applications that use complex AI capabilities. I integrated advanced audio processing systems for transcription, denoising and translation across multiple languages. I then expanded into image processing solutions for humanitarian crisis response.

<b>Front-end architecture:</b> I designed mission-critical applications with React, TypeScript and Next.js, using MUI components and a focus on Core Web Vitals. I used React GL to build complex geospatial interfaces. These gave humanitarian early warning systems interactive maps.

<b>Performance improvement:</b> I used standard front-end profiling tools to find performance bottlenecks. This matters in the resource-constrained environments our users face. I used code-splitting, lazy loading and SSR/SSG techniques to reduce bundle sizes and load times. I also made advanced React rendering improvements to create a great UX.

<b>Progressive web applications:</b> I built offline-first PWAs with local-first, optimistic UI and RTL support. Our users in Syria need these applications. Their environments are challenging, their connectivity is intermittent and their mobile devices are low-cost.

<b>Modern development stack:</b> I moved many repositories to modern JavaScript development tools like pnpm, Vite and Vitest. I replaced a couple of GraphQL-based applications with Next.js. Next.js gives server-side rendering and easy API integration between client and server.

<b>Serverless architecture:</b> I designed and built distributed serverless applications with AWS CDK, SST, Serverless framework and Terraform. This approach reduced our operational burden, made it easier to meet security requirements and increased our speed and agility.
