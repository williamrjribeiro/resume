<b>Engineering leadership:</b> A promotion to Principal Engineer came with a bonus job: unofficial tech lead of a product team. I led cross-functional teams. I set the technical vision for secure web applications. I also worked in the front-end and back-end codebases every day. I took on more: defining the engineering culture, making technical stack decisions, maintaining excellence across teams, shaping the technical side of hiring, mentoring, and more.

<b>AI-powered solutions:</b> Researchers built the AI. I built the applications people touch. I worked closely with AI researchers, ML specialists, and ETL data engineers. Together we delivered user-facing applications with complex AI capabilities. I integrated advanced audio processing for transcription, denoising, and translation across multiple languages. Then I added image processing for humanitarian crisis response.

<b>Frontend architecture:</b> Some of my maps are early warning systems. I used React GL for complex geospatial interfaces. They deliver interactive maps for humanitarian early warning systems. I architected mission-critical applications with React, TypeScript, and Next.js with MUI components. I focused on Core Web Vitals.

<b>Performance optimization:</b> Slow software fails the users who can least afford it. I used standard front-end profiling tools to find performance bottlenecks. Our users work in resource-constrained environments. I implemented code-splitting, lazy loading, and SSR/SSG techniques. Bundles got smaller. Load times dropped. I also optimized React rendering for a great UX.

<b>Progressive web applications:</b> Some of my users have no reliable internet. I built for them. I engineered offline-first PWAs with local-first, optimistic UI and RTL support. Our users in Syria depend on them. They face challenging environments, intermittent connectivity, and low-cost mobile devices.

<b>Modern development stack:</b> I replaced a couple of GraphQL-based applications with Next.js. Next.js brings server-side rendering. It also makes API integration between client and server easy. I migrated many repositories to modern JavaScript development tools like pnpm, Vite, and Vitest.

<b>Serverless architecture:</b> Serverless cut our operational burden. I designed and implemented distributed serverless applications with AWS CDK, SST, Serverless framework, and Terraform. Compliance with security requirements got simpler. Our speed and agility went up.
