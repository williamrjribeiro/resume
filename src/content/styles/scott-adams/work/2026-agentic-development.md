<b>Learning by building:</b> AI changes every month. Reading about it is not enough. I test AI tools on real software. I use Claude Code and Cursor, including Cursor's cloud agents. I compare planning modes, prompting styles, and spec-driven frameworks such as GSD. I keep what works. I drop what doesn't. I write down why.

<b>Evaluating AI agents:</b> I taught AI agents when to use Git worktrees. I also taught them when to use stacked pull requests. I built Verdant for that. Verdant is a private Tessl workspace with two skill packages. It has nine levelled eval scenarios with weighted rubrics, blocking failures, and adversarial cases. They run against a pinned, Bash-validated fixture repository. I planned the work with GSD in 5 phases, 21 plans, and 56 tasks. Contract tests, path-scoped CI, and a verified publish dry-run back it up.

<b>Parallel agents, human review:</b> I managed a crew of AI agents and merged all their work into one pull request. The agents ran in parallel Git worktrees. They built a 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook). I sent the hardest stories to a stronger model. I sent the rest to a faster one. I reviewed everything. The project reached 290 tracked issues and 199 commits in under four weeks.

<b>Specs and quality gates:</b> No agent writes code without a spec. Every feature starts with a written spec and user stories. I track them in Beads, an issue tracker built for agents. The agents work behind a pre-commit hook that mirrors CI. They also face behavior-driven tests, Storybook, and screenshot-based visual checks. Hexkit, my contract-driven API generator, was spec-first too. It got an RFC and a PRD before any code. Then it got a 90% coverage gate.

<b>Improving the process:</b> I change my workflow when the results say so. Review overhead and token costs piled up. So I moved from stacked pull requests to one epic branch. I replaced manual visual checks with screenshot comparison. I turned a long `AGENTS.md` into reusable skills. I packaged the lessons as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter).
