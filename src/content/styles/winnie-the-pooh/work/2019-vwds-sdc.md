<b>Founding Product Team Member:</b> I was one of the first to join the product team in the new Lisbon office. We solved real problems for the customers and dealerships of VW. I built friendships with clients through clear writing and talking, and I thought hard about tricky dealership workflows. After intensive onboarding in Berlin with our experienced German colleagues, I quickly took up Extreme Programming (XP) practices, including test-driven development and pair programming. Pair programming is two people at one computer, which seems very sensible.

<b>Frontend Excellence:</b> I made web applications with React and TypeScript that bend to every screen and let everyone in. I used Storybook to write down the components. I brought in MobX state management and taught it to the team, and rendering got much quicker. Many teams used the patterns that came from it.

<b>Engineering Practices:</b> I took up DevOps culture, with Infrastructure as Code, AWS cloud services, and GitHub Actions for continuous integration pipelines. I cheered for TDD with Jest and React Testing Library. I wrote end-to-end tests with Nightwatch.js, so every browser is treated the same.

<b>Technical Leadership:</b> I held technical interviews as pairing sessions, with TDD. I helped colleagues learn how to see technical skill fairly. This made the hiring process of the organization stronger.

<b>Full-Stack Development:</b> I built sturdy backend services and REST APIs with Golang and Kotlin and PostgreSQL databases, using domain-driven design principles. I also designed and made the first public website of the company (vwds.pt). It shows what our software team can do and how we like to work.
