<b>Learning by building:</b> Let me think. AI tools change every month. So I try them on real software, and I do not just read about them. I use Claude Code and Cursor, including the cloud agents of Cursor. I compare planning modes, prompting styles, and spec-driven frameworks such as GSD. What works, I keep. What does not, I put down, and I write down why.

<b>Evaluating AI agents:</b> I built a thing called Verdant. It is a private Tessl workspace with two skill packages. They teach agents when to use Git worktrees, and when to use stacked pull requests. It has nine levelled eval scenarios with weighted rubrics, blocking failures, and adversarial cases. They run against a pinned, Bash-validated fixture repository. I made the plan with GSD: 5 phases, 21 plans, and 56 tasks. Contract tests, path-scoped CI, and a verified publish dry-run help it stand.

<b>Parallel agents, human review:</b> Many helpers can work at the same time, if each has a place to work. I told background agents to work in parallel Git worktrees. They built a 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook). The hardest stories went to a stronger model, and the rest went to a faster one. I looked at all the work and put it together in one pull request. The project reached 290 tracked issues and 199 commits in under four weeks.

<b>Specs and quality gates:</b> A good walk starts with a map. Every feature starts with a written spec and user stories. I keep them in Beads, an issue tracker made for agents. The agents work behind a pre-commit hook that mirrors CI. They also have behavior-driven tests, Storybook, and screenshot-based visual checks. Hexkit is my contract-driven API generator, and it was spec-first too. It had an RFC and a PRD before any code, and then a 90% coverage gate.

<b>Improving the process:</b> Sometimes the road I chose was a bit long. I change my workflow when the results say so. Review overhead and token costs piled up, so I moved from stacked pull requests to one epic branch. I replaced manual visual checks with screenshot comparison. I turned a long `AGENTS.md` into reusable skills. I packaged the lessons as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter).
