#### Product Development Team

<b>Interactive Data Visualization:</b> I made advanced reporting features for web applications. They show interactive graphs and data visualizations, made with React, Redux, and Recharts. Customers could find useful insights in their call center data. The data came from SQL and NoSQL databases.

<b>Full-Stack Implementation:</b> I built responsive, data-rich screens with friends from many kinds of teams. I used React, Redux Saga, and Apollo Client (GraphQL) to fetch data well. I also joined the old Backbone.js parts to the new ones while we moved to a modern architecture.

<b>Build System Optimization:</b> I set up Webpack, Babel, and Gulp pipelines with continuous integration. Builds got shorter, and the developers felt better about it.

<b>Testing & Quality:</b> I wrote complete test suites with Jest, Mocha, and Enzyme. They kept components reliable, stopped regressions in important customer-facing features, and met security requirements for enterprise software.

#### Design System Leadership

<b>Component Library Architecture:</b> I was the unofficial tech lead for the proprietary UI framework and the Design System team. I made reusable, accessible React components, so everyone had the same experience across enterprise applications.

<b>Cross-Team Collaboration:</b> I held onboarding sessions for product teams who came to the Design System. I gave technical guidance and support, and I looked after component releases and documentation. I thought and thought about a technical vision for the component architecture, so upgrades would hurt as little as possible.

<b>Developer Experience:</b> I wrote down the components in Storybook, with interactive examples. More people used them, and the design stayed the same all through the organization.

<b>Mentorship & Growth:</b> I coached summer interns on frontend best practices and Design System implementation. I walked beside them in their project work, in a kind and supportive place.
