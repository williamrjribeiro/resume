<b>Learning by building:</b> AI tools change every month, and keeping up is tiring. So I test them on real software instead of only reading about them. I use Claude Code and Cursor, including Cursor's cloud agents, and I compare planning modes, prompting styles, and spec-driven frameworks such as GSD. I keep what works, drop what doesn't, and write down why. Be curious, not judgmental.

<b>Evaluating AI agents:</b> Teaching agents good Git habits is hard, and measuring it is harder. So I built Verdant, a private Tessl workspace with two skill packages that teach agents when to use Git worktrees and when to use stacked pull requests. It has nine levelled eval scenarios with weighted rubrics, blocking failures, and adversarial cases, run against a pinned, Bash-validated fixture repository. I planned it with GSD in 5 phases, 21 plans, and 56 tasks, and backed it with contract tests, path-scoped CI, and a verified publish dry-run.

<b>Parallel agents, human review:</b> Handing work to many agents at once can feel risky. I stayed in the loop. I directed background agents in parallel Git worktrees to build a 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook). The hardest stories went to a stronger model and the rest to a faster one. I reviewed the work and merged it as one pull request. The project reached 290 tracked issues and 199 commits in under four weeks.

<b>Specs and quality gates:</b> Fast agents can make fast mistakes. So every feature starts from a written spec and user stories tracked in Beads, an issue tracker built for agents. The agents work behind a pre-commit hook that mirrors CI, with behavior-driven tests, Storybook, and screenshot-based visual checks. Hexkit, my contract-driven API generator, was spec-first too: an RFC and a PRD before code, then a 90% coverage gate.

<b>Improving the process:</b> My first workflow cost too much, and I had to admit it. Review overhead and token costs piled up. So I moved from stacked pull requests to one epic branch. I replaced manual visual checks with screenshot comparison, and I turned a long `AGENTS.md` into reusable skills. I packaged the lessons as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter). I brought it along in case it helps you.
