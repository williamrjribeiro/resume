<b>Learning by building:</b> I find that AI tools and techniques change from one month to the next, so I test them on real software instead of only reading about them, which seems the polite way to treat a tool. I use Claude Code and Cursor, including the cloud agents of Cursor, and I compare planning modes, prompting styles and spec-driven frameworks such as GSD. I keep what works, I put aside what does not, and I write down why.

<b>Evaluating AI agents:</b> I built Verdant, a private Tessl workspace with two skill packages that teach agents when to use Git worktrees and when to use stacked pull requests. It has nine levelled eval scenarios with weighted rubrics, blocking failures and adversarial cases, run against a pinned, Bash-validated fixture repository. I planned it with GSD in 5 phases, 21 plans and 56 tasks, and I am glad to say it is backed by contract tests, path-scoped CI and a verified publish dry-run.

<b>Parallel agents, human review:</b> I asked background agents, most politely, to work in parallel Git worktrees and build a 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook). I gave the hardest stories to a stronger model and the rest to a faster one. Then I reviewed everything with great care and merged it as one pull request. The project reached 290 tracked issues and 199 commits in under four weeks.

<b>Specs and quality gates:</b> Every feature starts from a written spec and user stories tracked in Beads, an issue tracker built for agents. The agents work behind a pre-commit hook that mirrors CI, with behavior-driven tests, Storybook and screenshot-based visual checks, so that nothing is done carelessly. Hexkit, my contract-driven API generator, was also spec-first: an RFC and a PRD before code, then a 90% coverage gate.

<b>Improving the process:</b> I was sorry to find that review overhead and token costs had piled up, so I changed my workflow, as one should when the results say so. I moved from stacked pull requests to one epic branch, I replaced manual visual checks with screenshot comparison, and I turned a long `AGENTS.md` into reusable skills. I packaged the lessons as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter), which I hope others may find useful.
