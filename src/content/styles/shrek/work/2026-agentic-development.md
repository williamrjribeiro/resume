<b>Learning by building:</b> AI tools change every month. Reading about them is not enough. I test them on real software. I use Claude Code and Cursor, including Cursor's cloud agents. I compare planning modes, prompting styles, and spec-driven frameworks such as GSD. I keep what works and drop what doesn't. Then I write down why, the way a good ogre keeps a diary.

<b>Evaluating AI agents:</b> Agents need to be taught when to use Git worktrees. I built Verdant to teach them. Verdant is a private Tessl workspace with two skill packages. They also cover when to use stacked pull requests. It has nine levelled eval scenarios with weighted rubrics, blocking failures, and adversarial cases. They run against a pinned, Bash-validated fixture repository. I planned it with GSD in 5 phases, 21 plans, and 56 tasks. Contract tests, path-scoped CI, and a verified publish dry-run hold it together. It has layers.

<b>Parallel agents, human review:</b> Agents are fast. They still need a grown-up to read the work. I directed background agents in parallel Git worktrees to build a 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook). The hardest stories went to a stronger model. The rest went to a faster one. I reviewed the work and merged it as one pull request. The project reached 290 tracked issues and 199 commits in under four weeks. That's a lot of mud moved.

<b>Specs and quality gates:</b> Agents without specs make a mess. Every feature starts with a written spec and user stories. I track them in Beads, an issue tracker built for agents. The agents work behind a pre-commit hook that mirrors CI, with behavior-driven tests, Storybook, and screenshot-based visual checks. Hexkit, my contract-driven API generator, was spec-first too. It got an RFC and a PRD before any code, then a 90% coverage gate.

<b>Improving the process:</b> My workflow wasn't perfect. I changed it when the results said so. Review overhead and token costs piled up like swamp mud, so I moved from stacked pull requests to one epic branch. I replaced manual visual checks with screenshot comparison. I turned a long `AGENTS.md` into reusable skills. I packaged the lessons as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter).
