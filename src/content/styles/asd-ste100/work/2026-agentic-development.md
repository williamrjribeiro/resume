<b>Practical learning:</b> AI tools and techniques change each month. I test them on real software. I do not only read about them. I use Claude Code and Cursor, with the cloud agents of Cursor. I compare planning modes, prompting styles and spec-driven frameworks, such as GSD. I keep what works. I stop the use of what does not work. I write down the reason.

<b>AI agent evaluation:</b> I built Verdant. Verdant is a private Tessl workspace with two skill packages. The packages teach agents when to use Git worktrees and when to use stacked pull requests. Verdant has nine levelled eval scenarios with weighted rubrics, blocking failures and adversarial cases. The scenarios run against a pinned fixture repository that Bash validates. I planned the work with GSD in 5 phases, 21 plans and 56 tasks. Contract tests, path-scoped CI and a verified publish dry-run support the work.

<b>Parallel agents, human review:</b> I directed background agents in parallel Git worktrees. They built a 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook). I sent the hardest stories to a stronger model. I sent the other stories to a faster model. I reviewed the work and merged it as one pull request. The project reached 290 tracked issues and 199 commits in less than four weeks.

<b>Specifications and quality gates:</b> Each feature starts from a written specification and user stories. I track them in Beads, an issue tracker for agents. The agents work behind a pre-commit hook that mirrors CI. They also use behavior-driven tests, Storybook and screenshot-based visual checks. Hexkit is my contract-driven API generator. It is also spec-first: I wrote an RFC and a PRD before the code. After that, a 90% coverage gate applies.

<b>Process improvement:</b> I change my workflow when the results show a better way. I moved from stacked pull requests to one epic branch. Review work and token costs increased. I replaced manual visual checks with screenshot comparison. I changed a long `AGENTS.md` file into reusable skills. I packaged the lessons as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter).
