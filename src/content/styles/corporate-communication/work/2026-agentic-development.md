<b>Learning by building:</b> I'm testing new AI tools on real software, not just reading about them, because they change from one month to the next. I use Claude Code and Cursor, including Cursor's cloud agents, and I compare planning modes, prompting styles and spec-driven frameworks such as GSD. I keep what works, drop what doesn't, and write down why.

<b>Evaluating AI agents:</b> I built Verdant, a private Tessl workspace with two skill packages that teach agents when to use Git worktrees and when to use stacked pull requests. It has nine levelled eval scenarios with weighted rubrics, blocking failures and adversarial cases, run against a pinned, Bash-validated fixture repository. I planned it with GSD in 5 phases, 21 plans and 56 tasks, and backed it with contract tests, path-scoped CI and a verified publish dry-run.

<b>Parallel agents, human review:</b> I directed background agents in parallel Git worktrees to build a 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook), and I reviewed and merged the work as one pull request. I sent the hardest stories to a stronger model and the rest to a faster one. The project reached 290 tracked issues and 199 commits in under four weeks.

<b>Specs and quality gates:</b> Every feature starts from a written spec and user stories tracked in Beads, an issue tracker built for agents. Agents work behind a pre-commit hook that mirrors CI, with behavior-driven tests, Storybook and screenshot-based visual checks. Hexkit, my contract-driven API generator, followed the same rule: an RFC and a PRD before code, then a 90% coverage gate.

<b>Improving the process:</b> I changed my workflow because the results told me to. Review overhead and token costs piled up, so I moved from stacked pull requests to one epic branch. I also replaced manual visual checks with screenshot comparison and turned a long `AGENTS.md` into reusable skills. I packaged the lessons as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter).
