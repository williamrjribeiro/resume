<b>Engineering leadership:</b> I was promoted to Principal Engineer and became the unofficial tech lead of one of our product teams. I led cross-functional teams and set the technical vision for secure web applications. Beyond my daily work in the front-end and back-end codebases, I took on many other responsibilities: defining the engineering culture, making technical stack decisions, maintaining excellence across teams, shaping the technical parts of hiring, mentoring, and more.

<b>AI-powered solutions:</b> I delivered user-facing applications built on complex AI capabilities, working closely with AI researchers, ML specialists, and ETL data engineers. I integrated advanced audio processing for transcription, denoising, and translation across multiple languages, then expanded into image processing for humanitarian crisis response.

<b>Frontend architecture:</b> I architected our mission-critical applications with React, TypeScript, and Next.js with MUI components, and I focused on Core Web Vitals. I implemented React GL for complex geospatial interfaces, which gave us interactive maps for humanitarian early warning systems.

<b>Performance:</b> I found performance bottlenecks with standard front-end profiling tools. That matters a lot in the resource-constrained environments our users work in. I implemented code-splitting, lazy loading, and SSR/SSG techniques to reduce bundle sizes and load times, and I improved React rendering to create a great UX.

<b>Progressive web applications:</b> I built offline-first PWAs with local-first, optimistic UI and RTL support. Our users in Syria need them: they face challenging environments with intermittent connectivity and use low-cost mobile devices.

<b>Modern development stack:</b> I migrated many repositories to modern JavaScript development tools like pnpm, Vite, and Vitest. I also replaced a couple of GraphQL-based applications with Next.js, which gave us server-side rendering and easy API integration between client and server.

<b>Serverless architecture:</b> I designed and implemented distributed serverless applications with AWS CDK, SST, Serverless framework, and Terraform. The result: a lighter operational burden, simpler compliance with security requirements, and more speed and agility.
