<b>Learning by building:</b> AI tools and techniques shift from one month to the next, like tides, so I test them on real software instead of merely reading the sea charts. I use Claude Code and Cursor, including the cloud agents of Cursor, and I compare planning modes, prompting styles and spec-driven frameworks such as GSD. What works, I keep in the hold. What does not, I toss overboard, and I write down why in the ship's log.

<b>Evaluating AI agents:</b> I built Verdant, a private Tessl workspace with two skill packages that teach agents when to sail with Git worktrees and when to use stacked pull requests. It holds nine levelled eval scenarios with weighted rubrics, blocking failures and adversarial cases, all run against a pinned, Bash-validated fixture repository: a very well-guarded harbor. I charted the voyage with GSD in 5 phases, 21 plans and 56 tasks. Contract tests, path-scoped CI and a verified publish dry-run kept the hull sound.

<b>Parallel agents, human review:</b> I sent a fleet of background agents sailing through parallel Git worktrees to build a 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook). The hardest stories went to a stronger model, and the rest to a faster one. Then I reviewed the plunder and merged it as one pull request. The project reached 290 tracked issues and 199 commits in under four weeks.

<b>Specs and quality gates:</b> Every feature sets sail from a written spec and user stories, tracked in Beads, an issue tracker built for agents. My agents work behind a pre-commit hook that mirrors CI, with behavior-driven tests, Storybook and screenshot-based visual checks: the harbor guards of the whole operation. Hexkit, my contract-driven API generator, was spec-first too: an RFC and a PRD before any code, then a 90% coverage gate.

<b>Improving the process:</b> When the results say the course is wrong, I change it. Review overhead and token costs piled up like barnacles, so I moved from stacked pull requests to one epic branch. I traded manual visual checks for screenshot comparison, and I turned a long `AGENTS.md` into reusable skills. The lessons are packaged as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter).
