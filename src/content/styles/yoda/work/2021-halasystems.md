I integrated advanced audio processing, for transcription, denoising, and translation in many languages. Image processing for humanitarian crisis response, I added after.

<b>Frontend Architecture:</b> Mission-critical applications, I designed. I built them with React, TypeScript, and Next.js and MUI components. Core Web Vitals, I watched. I used React GL for complex geospatial interfaces. Interactive maps for humanitarian early warning systems, they became.

<b>Progressive Web Applications:</b> Offline-first PWAs, I built. Local-first, optimistic UI and RTL support, they have. In Syria, our users need them. Hard places, they live. Their connection comes and goes. Cheap, their phones are.

<b>Modern Development Stack:</b> Many repositories, I moved to modern JavaScript development tools like pnpm, Vite, and Vitest. A couple of GraphQL-based applications, I replaced with Next.js. It brings server-side rendering. Easy, API integration between client and server becomes.

<b>Serverless Architecture:</b> Distributed serverless applications, I designed and built, with AWS CDK, SST, Serverless framework, and Terraform. Lighter, our operational burden became. Easier to meet, the security requirements. More speed and agility, we gained.
