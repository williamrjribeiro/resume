<b>Learning by building:</b> Each month, AI tools change. I do not only read about them. On real software, I test them. I use Claude Code and Cursor, with the cloud agents of Cursor. Planning modes, prompting styles, and spec-driven frameworks such as GSD, I compare. What works, I keep. What does not, I drop. Why, I write down.

<b>Evaluating AI agents:</b> Verdant, I built. A private Tessl workspace it is, with two skill packages. They teach agents when to use Git worktrees and when to use stacked pull requests. It has nine levelled eval scenarios, with weighted rubrics, blocking failures, and adversarial cases. Against a pinned, Bash-validated fixture repository, they run. With GSD, I planned it: 5 phases, 21 plans, 56 tasks. Contract tests, path-scoped CI, and a verified publish dry-run support it.

<b>Parallel agents, human review:</b> Many agents, I directed. In parallel Git worktrees, they worked. A 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook), they built. The hardest stories went to a stronger model. The rest went to a faster one. I reviewed all the work. I merged it as one pull request. In under four weeks, the project reached 290 tracked issues and 199 commits.

<b>Specs and quality gates:</b> With a written spec, each feature begins. I track user stories in Beads, an issue tracker built for agents. Behind a pre-commit hook that mirrors CI, the agents work. They face behavior-driven tests, Storybook, and screenshot-based visual checks. Hexkit, my contract-driven API generator, was spec-first too. An RFC and a PRD came before code. Then, a 90% coverage gate.

<b>Improving the process:</b> When results say so, my workflow I change. Review overhead and token costs piled up. So I moved from stacked pull requests to one epic branch. Manual visual checks, screenshot comparison replaced. A long `AGENTS.md` became reusable skills. I packaged the lessons as eight repository skills and an open-source starter template, [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter). Learn always, we must.
