<b>Engineering Leadership:</b> I was promoted to Principal Engineer and became the unofficial tech lead of one of the product teams. I led cross-functional teams and helped set a clear technical vision for secure web applications. Besides my daily contributions to the front-end and back-end codebases, I looked after many other initiatives: shaping the engineering culture, making technical stack decisions, keeping excellence strong across teams, helping with the technical parts of hiring, mentoring, and more.

<b>AI-Powered Solutions:</b> I worked closely with AI researchers, ML specialists, and ETL data engineers to deliver user-facing applications built on complex AI capabilities. I integrated advanced audio processing for transcription, denoising, and translation across many languages, and then added image processing solutions for humanitarian crisis response.

<b>Frontend Architecture:</b> I designed mission-critical applications with React, TypeScript, and Next.js with MUI components, with a calm focus on Core Web Vitals. I implemented React GL for complex geospatial interfaces and delivered interactive maps for humanitarian early warning systems.

<b>Performance Optimization:</b> I used standard front-end profiling tools to find performance bottlenecks, which matters a great deal in the resource-constrained environments our users face. I implemented code-splitting, lazy loading, and SSR/SSG techniques to shrink bundle sizes and improve load times, and I added careful React rendering optimizations for a great UX.

<b>Progressive Web Applications:</b> I built offline-first PWAs with local-first, optimistic UI and RTL support. These applications are essential for our users in Syria, who face challenging environments with intermittent connectivity and use low-cost mobile devices.

<b>Modern Development Stack:</b> I migrated many repositories to modern JavaScript development tools like pnpm, Vite, and Vitest. I replaced a couple of GraphQL-based applications with Next.js, which gave us server-side rendering and easy API integration between client and server.

<b>Serverless Architecture:</b> I designed and implemented distributed serverless applications with AWS CDK, SST, Serverless framework, and Terraform. This approach lightened our operational burden, made compliance with security requirements simpler, and gave us more speed and agility.
