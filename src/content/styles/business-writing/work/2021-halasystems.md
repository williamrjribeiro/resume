<b>Engineering leadership:</b> I was promoted to Principal Engineer and became the unofficial tech lead of one product team. I led cross-functional teams and set the technical vision for secure web applications. Beyond my daily work in the front-end and back-end codebases, I owned several initiatives: defining the engineering culture, making technical stack decisions, maintaining excellence across teams, shaping the technical side of hiring, and mentoring.

<b>AI-powered solutions:</b> I delivered user-facing applications built on complex AI capabilities, working closely with AI researchers, ML specialists, and ETL data engineers. I integrated audio processing for transcription, denoising, and translation across multiple languages, then expanded into image processing for humanitarian crisis response.

<b>Frontend architecture:</b> I architected mission-critical applications with React, TypeScript, and Next.js with MUI components, and focused on Core Web Vitals. I implemented React GL for complex geospatial interfaces and delivered interactive maps for humanitarian early warning systems.

<b>Performance:</b> I found performance bottlenecks with standard front-end profiling tools, which matters in the resource-constrained environments our users face. I implemented code-splitting, lazy loading, and SSR/SSG techniques to cut bundle sizes and load times. I also tuned React rendering for a better UX.

<b>Progressive web applications:</b> I built offline-first PWAs with local-first, optimistic UI and RTL support. Our users in Syria depend on them: they face intermittent connectivity and use low-cost mobile devices.

<b>Modern development stack:</b> I migrated many repositories to modern JavaScript development tools: pnpm, Vite, and Vitest. I replaced a couple of GraphQL-based applications with Next.js, which provides server-side rendering and simple API integration between client and server.

<b>Serverless architecture:</b> I cut our operational burden, simplified compliance with security requirements, and increased our speed and agility. I designed and implemented distributed serverless applications with AWS CDK, SST, Serverless framework, and Terraform.
