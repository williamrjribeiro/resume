<b>Learning by building:</b> AI tools and techniques change from one month to the next, so William tests them on real software instead of only reading about them. He uses Claude Code and Cursor, including the cloud agents of Cursor, and compares planning modes, prompting styles, and spec-driven frameworks such as GSD. He keeps what works, drops what doesn't, and writes down why.

<b>Evaluating AI agents:</b> Verdant is a private Tessl workspace with two skill packages that teach agents when to use Git worktrees and when to use stacked pull requests. It contains nine levelled eval scenarios with weighted rubrics, blocking failures, and adversarial cases, and it runs them against a pinned, Bash-validated fixture repository. William planned the work with GSD in 5 phases, 21 plans, and 56 tasks, and backed it with contract tests, path-scoped CI, and a verified publish dry-run.

<b>Directing parallel agents:</b> To build a 19-story redesign of a guitar-lesson player (SolidJS, Bun, Storybook), William directed background agents in parallel Git worktrees. He sent the hardest stories to a stronger model and the rest to a faster model, then reviewed and merged the work as one pull request. The project reached 290 tracked issues and 199 commits in under four weeks.

<b>Specifying and gating quality:</b> Every feature starts from a written spec and user stories tracked in Beads, an issue tracker built for agents. Agents work behind a pre-commit hook that mirrors CI, with behavior-driven tests, Storybook, and screenshot-based visual checks. Hexkit, William's contract-driven API generator, follows the same rule: an RFC and a PRD come before code, followed by a 90% coverage gate.

<b>Improving the process:</b> William changes the workflow when the results say so. After review overhead and token costs piled up, he moved from stacked pull requests to one epic branch. He replaced manual visual checks with screenshot comparison and turned a long `AGENTS.md` into reusable skills. To reuse the lessons, see the eight repository skills and the open-source starter template [bun-agentic-starter](https://github.com/williamrjribeiro/bun-agentic-starter).
