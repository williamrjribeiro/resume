<b>Engineering leadership:</b> I was promoted to Principal Engineer and became the unofficial tech lead of one of the product teams. I led teams of mixed skills and set the technical vision for secure web applications. Besides my daily work in the front-end and back-end codebases, I took on much else: I defined the engineering culture, chose the technical stack, kept standards high across teams, shaped the technical side of hiring, mentored, and more.

<b>AI-powered solutions:</b> I worked closely with AI researchers, ML specialists and ETL data engineers to deliver user-facing applications built on complex AI. I added audio processing for transcription, denoising and translation in many languages. Then I added image processing for humanitarian crisis response.

<b>Frontend architecture:</b> I designed mission-critical applications with React, TypeScript and Next.js, using MUI components and watching Core Web Vitals. I used React GL for complex geospatial interfaces, which gave humanitarian early warning systems interactive maps.

<b>Performance:</b> I used standard front-end profiling tools to find slow spots. This matters where our users have little to work with. I split code, loaded it lazily and used SSR/SSG techniques to shrink bundles and cut load times. I also tuned how React renders, for a great UX.

<b>Progressive web applications:</b> I built offline-first PWAs with local-first, optimistic UI and RTL support. Our users in Syria need them. Their conditions are hard, their connection comes and goes, and their phones are cheap.

<b>Modern development stack:</b> I moved many repositories to modern JavaScript development tools like pnpm, Vite and Vitest. I replaced a couple of GraphQL-based applications with Next.js, which renders pages on the server and makes API integration between client and server easy.

<b>Serverless architecture:</b> I designed and built distributed serverless applications with AWS CDK, SST, Serverless framework and Terraform. This lightened the work of running them, made security requirements easier to meet and gave us more speed and agility.
