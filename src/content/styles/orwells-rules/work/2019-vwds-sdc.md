<b>Founding product team member:</b> I was one of the first hired to set up the product team in the Lisbon office. We solved real problems for the customers and dealerships of VW. I built client relationships through clear writing and speech, and I thought hard about complex dealership workflows. After intensive onboarding in Berlin with our experienced German colleagues, I soon adopted Extreme Programming (XP) practices, including test-driven development and pair programming.

<b>Frontend excellence:</b> I built responsive, accessible web applications with React and TypeScript, and documented components in Storybook. I introduced MobX state management and taught it to the team, which sped up rendering a great deal. Several teams copied the architecture patterns that came of it.

<b>Engineering practices:</b> I took up DevOps culture, with Infrastructure as Code, AWS cloud services and GitHub Actions for continuous integration pipelines. I pushed TDD with Jest and React Testing Library. I wrote end-to-end tests with Nightwatch.js to make sure the applications work in every browser.

<b>Technical leadership:</b> I ran technical interviews as pairing sessions using TDD. I coached colleagues on how to judge technical skill, which made our hiring stronger.

<b>Full-stack development:</b> I built sturdy backend services and REST APIs with Golang and Kotlin on PostgreSQL databases, following domain-driven design principles. I also designed and built the company's first public website (vwds.pt), which shows what our software team can do and how we work.
